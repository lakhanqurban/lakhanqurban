### 🔭 What I work on

I research how to make testing of **Autonomous Driving Systems (ADS)** more efficient and trustworthy — focusing on:

- **Regression testing** — deciding what to re-test as ADS software evolves, without re-running everything
- **Test prioritization** — coverage-guided selection of driving scenarios/roads for efficient testing
- **Interoperability** — bridging simulation formats (e.g. OpenDRIVE) and toolchains used across ADS platforms
- **Runtime verification** — monitoring signal temporal logic (STL) properties and injecting geometric faults to stress-test system robustness
